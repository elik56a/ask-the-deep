# Skills

## Programming languages

Eliyahu programs in JavaScript, TypeScript, Python and Java. He uses Python for AI engineering and backend services.

## TypeScript

TypeScript is Eliyahu's main language. He writes strictly typed code across React, React Native, Node.js and build tooling: Phytech's shared packages publish their own TypeScript type declarations, its common types are shared between the apps and the server, and its publish and release scripts are written in TypeScript.

## Java

Eliyahu works with Java at Phytech. He changed the company's Java AI worker, a Maven project, to support several AI providers through LangChain4j instead of the OpenAI Java SDK, with JUnit tests. He also integrates Phytech's Node.js API with its Java services and their data.

## Python

Eliyahu uses Python for AI engineering. He built this portfolio's chat agent in Python with FastAPI and Pydantic AI, with strict mypy typing, Ruff and pytest, and retrieval over PostgreSQL with pgvector.

## Frameworks and libraries

Eliyahu works with React, React Native, Expo, Node.js, Express.js, Next.js and FastAPI. He has also built with Vue.js.

## Frontend architecture

Eliyahu builds React and React Native apps with MobX stores and view stores, shared component libraries, and config-driven screens and forms. He builds for web and mobile from one shared codebase, and cares about accessibility, keyboard use, reduced motion and right-to-left layouts.

## Data visualization

Eliyahu builds data-heavy interfaces: time-series charts with ECharts and ApexCharts, interactive schematic diagrams of system topology, maps with markers and polygons, and three.js scenes. He tunes them for performance, for example by drawing only the visible time window of a long series.

## Mobile development

Eliyahu builds mobile apps with React Native and Expo, with maps, push notifications, deep links, over-the-air updates, crash reporting with Bugsnag and analytics with Mixpanel. He has worked on Phytech's mobile app since 2022.

## Backend development

Eliyahu builds backend services with Node.js, Express and TypeScript, using dependency injection with Inversify, PostgreSQL functions and query tuning, Redis caching and RabbitMQ messaging. He also builds Python services with FastAPI, and earlier built Node.js services on OracleDB.

## AI-assisted development

Eliyahu builds AI-assisted development platforms with Claude Code, including custom plugins, hooks, rules and skills. He also works with Cursor, LLM context engineering and MCP (Model Context Protocol).

## AI engineering

Eliyahu builds applications on top of large language models: retrieval-augmented generation (RAG) with hybrid vector and keyword search, tool-calling agents with Pydantic AI, multi-provider model access with LangChain4j, evaluation sets with an LLM judge, guardrails, and cost tracking per call.

## Testing and quality

Eliyahu writes tests as part of every change, with Jest for TypeScript and pytest for Python. At Phytech he owns the testing strategy and drove test coverage to nearly 100%. He enforces quality with tooling: linting with ESLint, Biome and Ruff, strict type checking, and Claude Code hooks that run the relevant tests on every change.

## Infrastructure and DevOps

Eliyahu works with AWS (S3 and CloudFront), Terraform for infrastructure as code, CI/CD pipelines and Yarn Workspaces monorepos.

## CI/CD and release automation

Eliyahu writes CI/CD pipelines with GitHub Actions, and has migrated pipelines from CircleCI. He builds release automation for monorepos: detecting which packages changed, versioning and publishing them to npm in parallel, release channels per branch, and rolling new versions out to the apps that use them.

## Databases and messaging

Eliyahu has worked with MySQL, PostgreSQL, MongoDB, Firebase, Redis, RabbitMQ and OracleDB, including database design and optimization.

## Real-time communication

Eliyahu has built real-time features with WebRTC, Socket.io and Twilio, including live video consultations, and has used server-sent events to stream an AI agent's steps to the browser.
